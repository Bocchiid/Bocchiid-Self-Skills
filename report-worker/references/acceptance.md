# 验收与完成标准

## 闸门总览

| 闸门 | 问题 | 命令 |
| --- | --- | --- |
| G0 授权/环境 | 用户同意了吗？环境/依赖就绪吗？ | `env.py --probe` / `capabilities.json` |
| G1 计划 | 目的-步骤-证据完整吗？`plan.json` 能解析吗？ | `verify.py plan` |
| G2 步骤 | 这一步的退出码/输出/文件/画面符合吗？ | `verify.py step` |
| G3 证据 | L1 都通过了吗？文件/哈希/字段对吗？ | `verify.py evidence` |
| G4 报告 | 能打开吗？格式跟模板一致吗？ | `verify.py report` |
| G5 审核 | 有阻断项吗？ | `verify.py review` |
| G6 交付 | DoD 全部满足吗？ | `verify.py dod` |

## 计划验收

- 每个目的至少一个步骤 + 一个证据；
- 每步有 `goal`、`action.kind`、至少一条 `acceptance`、至少一条 `evidence`；
- 证据 ID/步骤 ID/阶段 ID 不重复，引用都存在；
- `gui` 步骤有 app/window/control 或 instruction；
- `command` 步骤有 commands 或 instruction；
- 没有把流程图/示意图列成用户截图（应在 `writer_figures`）。

## 步骤验收

支持的类型：

| 类型 | 说明 |
| --- | --- |
| `exit_code` | 命令退出码等于期望 |
| `stdout_regex` | 标准输出匹配正则 |
| `stderr_regex` | 标准错误匹配正则 |
| `file_exists` | 文件存在 |
| `file_contains` | 文件内容匹配正则 |
| `json_field` | JSON 字段等于期望 |
| `visual` | 必须看画面，交给截图验收 |
| `manual` | 必须用户确认 |

结果：

- `pass`：所有非视觉/非人工检查通过；
- `partial`：有视觉/人工检查待定；
- `fail`：有检查失败。

`partial` 不要当 `pass` 用；先截图验收或让用户确认。

## 证据验收（四查）

1. **对应步骤**：文件 → 证据 ID → 计划步骤；
2. **必须包含**：`must_include` 逐项；
3. **预期结果**：该步骤的 `acceptance`；
4. **可读性**：完整窗口、关键字段清晰、没裁掉标题栏/命令/输出。

判定：`通过` / `部分通过` / `不通过` / `需人工复核`。

不通过时写：缺什么、重截哪里、预期画面是什么。不要只说“重截”。

## 证据清单检查

`verify.py evidence` 会查：

- 文件存在；
- SHA256 与清单一致（防止事后替换/伪造）；
- 状态是 `通过`/`pass`/`ok`；
- L1 数量 > 0 且全部通过。

非截图证据（数据/日志/代码）同样要进清单。

## 报告验收

- 文件存在、非空；
- `.docx` 是有效 zip，python-docx 能打开；
- `.doc` 是 OLE 文件；
- 扩展名与模板一致；
- 最终还要 PDF 预览翻一遍（writer 的自检）。

模板保护区（封面、评分表、页眉页脚、预填内容）由 writer 的自检负责；worker 至少检查
文件可打开和格式一致。

## 审核验收

`verify.py review` 解析：

- `审核结论`：通过/有条件通过/不通过；
- `总分区间`；
- 问题分组：【正确性错误】【格式问题】【要求未满足】【模板保护问题】。

阻断项：

- 结论 `不通过`；
- 【正确性错误】有内容；
- 【要求未满足】有内容；
- 【模板保护问题】有内容。

“建议/可选”不算阻断；不要为了清零把正确内容删掉。

## DoD

全部满足：

- 计划冻结；目的全覆盖；
- L1 证据全通过；
- 审核通过，或仅有条件通过且只剩建议/可选；
- 零正确性错误、零要求未满足、零模板保护问题；
- 硬要求 100%；
- 报告可打开、格式一致；
- 每条证据可追溯；
- 最后一轮无新增阻断。

## 停止条件

- DoD 达成；
- 报告轮次用完（默认 3）；
- 单步重试用完（默认 3）；
- 同一问题连续 2 轮未修复；
- 预算/权限/环境阻塞；
- 用户要求停。

停止时输出 `BLOCKED` 报告：已尝试什么、卡在哪、用户下一步做什么。
