# 结构审计：模板、表格、公式、跨软件

这一页列的是“内容看着没问题，但打开/批改时会翻车”的硬检查。**优先级高于文风建议。**

## 一、先跑自动审计

```bash
python scripts/parse_docx.py --audit 报告.docx --template 模板.docx
```

输出字段：

| 字段 | 含义 |
| --- | --- |
| `compatibility_mode` | 应为 15；11 = Word 2003，公式会被转图片 |
| `omml_count` | OMML 公式数 |
| `inline_shapes` | 内联图形数；异常增多可能是公式变图片 |
| `tables.top_level` / `all` / `nested` | 表格数 |
| `tables.wrappers` | 疑似 1×1 外层包裹表 |
| `tables.no_blank_after` | 表格后没有空段落 |
| `formula_paragraphs` | 公式段落未左对齐/未关闭 autoSpace |
| `omml_structure` | 分式空 `m:den`/`m:num`、空上下标、空求限、函数参数疑似进 `m:sub` |
| `western_runs` | 非中文 run 缺显式字体 |
| `template_compare` | 模板骨架差异 |

## 二、模板骨架（最高优先级）

逐项核对：

- 行数是否与模板一致；
- 每行格数是否一致；
- 横向合并 `gridSpan`、纵向合并 `vMerge` 是否一致；
- 左侧栏目名/固定文字是否一致；
- 有没有为了“摘要/结论/参考文献”新增行。

**处理口径**：

- 加行/删行/改栏目名 → 【模板保护问题·结构硬伤】，不是“格式建议”；
- 评分表要求摘要但模板没位置 → 先看学生是否嵌进“问题描述”开头；
  若学生加了一行，按要求指出应回退到嵌入写法；
- 不要求学生改模板来“补”评分项。

## 三、表格

- [ ] 没有 1×1 外层包裹表（1×1 表里嵌表，或 1×1 表里放“表 X”表题）
- [ ] 每张表后有空段落
- [ ] 三线表：左右边框、内部竖线为 `nil`
- [ ] 单元格左右留白约 80 twips
- [ ] 表格总数 = 主表 + 数据表，多出的表有合理解释
- [ ] 表头不换行、长单元格不超过 3 行

## 四、公式

显示公式：

- `m:den` 非空，分母在 `m:den` 内；
- 函数参数没有落进 `m:sub`；
- 求和上下限、上下标没有空 `m:e` / `m:sub` / `m:sup`。

行内公式：

- 段落显式 `w:jc=left`；
- `autoSpaceDE` / `autoSpaceDN` 为 `0`；
- 非中文 run 有显式 `Times New Roman`（ascii/hAnsi/eastAsia/cs，hint=default）；
- 没有一刀切全转 OMML 导致长公式顶出单元格。

## 五、图片/流程图

- [ ] 箭头有杆身，不是只有箭头头
- [ ] 文字与框线有内边距，没有压框
- [ ] 标签不在箭头线上
- [ ] 判定框足够高，文字没有挤成多行
- [ ] 按最终插入宽度可读
- [ ] 图题与图同页
- [ ] 左右对比图两栏都正常

## 六、跨软件

- [ ] `compatibilityMode=15`
- [ ] Word 保存往返后 OMaths 数量不变、InlineShapes 不增加
- [ ] `.doc` 交付已说明显示公式会变图片
- [ ] WPS 四项：表格外圈、行内公式角标、两端对齐拉伸、关闭提示

**没有 WPS 实机**：在审核报告里单列“WPS 实机确认”，写
“结构层面已处理，需用户在 WPS 中确认”，**不要混进“已通过”**。

## 七、结构问题分级

| 问题 | 级别 | 处理 |
| --- | --- | --- |
| 模板加行/删行/改栏目名 | 致命 | 必须回退，不能只扣格式分 |
| 1×1 外层包裹表 | 致命 | 删除外层表，改 `table_block` |
| `compatibilityMode=11` | 高 | 改 15，重做保存往返测试 |
| 公式 `m:den` 为空/分母跑出 | 高 | 重建 OMML 结构 |
| 表格后无空行 | 中 | 补空段落 |
| 三线表左右边框不是 nil | 中 | 改边框 |
| 行内公式角标间距大 | 中 | 查对齐/字体/Unicode |
| 箭头只有头 | 中 | `shrinkA=shrinkB=0`，重算端点 |
| 文字压框 | 中 | 加内边距/移标签 |
