# 表格：不要外层表，表后要空行

## 一、绝对不要用 1×1 外层表包“表题 + 表格”

这是最容易踩、且 Word 里看不出来的坑：

- **Word**：1×1 无边框表看起来正常。
- **WPS**：会在数据表外再显示一圈表格边框，同学一眼就能看到“表格外面套了一层表”。

正确结构（`K.table_block()` / `cur.put_table()` 已按此实现）：

```text
表题段落（keepNext）
三线表 / 数据表（每行 cantSplit，除最后一行外 keepNext）
空段落（tiny，占一行间距）
```

```python
cur.put_table(caps, 'tab_host', '主机地址规划', rows, widths,
              three_line=True, split=False)
```

`split=True` 时允许整表跨页续排，换取页面填满；此时行内 `keepNext` 关闭，
但每行仍 `cantSplit`，不会把一行拦腰截断。

### 为什么表题和表格还能同页

1. 表题段落显式 `w:keepNext`；
2. 表格除最后一行外的所有行都带 `keepNext`；
3. 每行 `cantSplit`。

不需要、也不允许再加外层表。

## 二、表格后必须空一行

- 文档层面：表格后补一个空段落，满足“表格后空一行”。
- 单元格层面：`w:tc` 的最后一个块级元素不能是 `w:tbl`，否则 Word 打开报
  “文件内容已经损坏”。同一个空段落同时满足这两条。

`table_block(blank_after=True)` 默认补**正常空段落**；自己用 `make_table()` 时，
调用方必须补 `K.new_p()`。不要用 1pt 的 tiny 段落代替——那只是占位，
肉眼看不到“空一行”。

## 三、三线表

`three_line=True` 时：

- 顶线、底线：`single`，`sz=6`；
- 表头行底部：`tcBorders/w:bottom`，`single`，`sz=6`；
- 左、右、内部横线、内部竖线：`nil`。

检查时看 `w:tblBorders` 里 `left/right/insideV` 是否为 `nil`；如果是 `single`，
说明不是三线表。

## 四、单元格留白与列宽

- `tblCellMar` 左右各 80 twips（约 0.14 cm）。不留白时相邻列文字会贴在一起，
  WPS 尤其明显。
- 列宽按**中英文混排的实际长度**核对，不要平均分：
  - 表头不能换行；
  - 长单元格不能挤成 3 行以上；
  - 数字列可以窄，说明列要宽。
- `tblLayout=fixed`，避免 Word 自动重排列宽。

## 五、交付前数表格

```python
top, all_count = K.table_counts(doc)
```

- 预期：**主表 + N 张数据表**（加上模板原有表格）。
- 如果 `all_count` 比预期多出与图表数量相近的数目，通常是 1×1 外层包裹表没删干净。
- 嵌套表格（框里的题目表、信息表）也要计入，但它们是模板原有的，不要删。
