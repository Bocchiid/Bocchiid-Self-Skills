# 通用 GUI 操作提示

## 先看

1. `list-windows`：确认窗口标题、位置、大小；
2. `uia list --window <标题>`：看控件名/AutomationId；
3. 截一张当前屏幕：确认可见状态；
4. 想清楚：**点哪里、点完应该看到什么**。

## 再动

- 能用控件名就不用坐标；
- 能用键盘/菜单就不用鼠标；
- 坐标必须归一化 + `--confirm`；
- 动作用 `desktop.py act --file`，不要直接 `SendKeys` 一堆。

## 再验证

- `expect` 写可观察的变化：文字出现、文件落盘、画面明显变化；
- 动作前后截图；
- 验证失败：先看窗口是否在前台、是否加载中、目标是否被遮挡；
- 不要连续重试同一个坐标。

## 失败升级

1. 换控件名/自动化 ID；
2. 换键盘/菜单；
3. 换归一化坐标；
4. 人工接管（生成操作卡）。

## 安全

- 不点未知弹窗；
- 不关闭不认识的窗口；
- 不替用户登录/提交/购买；
- 删除/覆盖/安装/提权先确认。
