# 默认评分标准

当模板或要求文档中没有评分标准时，使用本默认标准。

## 专业课（网络工程、编程）

| 维度       | 满分 | 评分要点                                                     |
| ---------- | ---- | ------------------------------------------------------------ |
| 正确性     | 30   | 事实、命令、代码、逻辑有无错误。每处明确错误扣 3~5 分，疑似错误扣 1~2 分 |
| 内容完整性 | 30   | 是否覆盖模板所有必填章节和子任务。缺一项扣 5~10 分           |
| 要求对标   | 25   | 是否按题目要求完成，有无偏离。字数不足按比例扣分             |
| 格式规范   | 15   | 字体字号、标题层级、图表编号、标点统一。每类问题扣 2~3 分    |

## 公选课

| 维度       | 满分 | 评分要点                                           |
| ---------- | ---- | -------------------------------------------------- |
| 内容完整性 | 35   | 是否覆盖所有子问题，论述是否充分                   |
| 要求对标   | 30   | 字数是否达标、是否按要求"自己写"、是否覆盖指定角度 |
| 正确性     | 20   | 概念、数据、引用有无错误                           |
| 格式规范   | 15   | 标题层级、段落排版、术语统一                       |

## 评分档位换算

若模板使用五档制（优秀/良好/中等/及格/不及格），换算规则：

- 优秀：90~100
- 良好：80~89
- 中等：70~79
- 及格：60~69
- 不及格：60 以下

输出时给出档位对应分数区间。
