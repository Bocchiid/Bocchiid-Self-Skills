# 无模板 / 纯文科自由写作

当用户没有课程模板，或任务是论文、书评、调研报告、案例分析、商业计划、读书报告时，
不要硬套实验报告模板，也不要凭空发明“标准格式”。先问清楚，再协商结构。

## 1. 先问什么

一次问完，不要边写边问：

- 交付格式：`.doc` / `.docx` / PDF / Markdown？
- 字数/页数：下限、上限、是否含摘要/参考文献？
- 是否要：标题页、摘要、目录、关键词、附录、致谢？
- 标题层级：`一、二、三` / `1. 2. 3.` / `1.1`？
- 引用规范：GB/T 7714、APA、MLA、Chicago、还是老师自定？
- 读者/课程：老师、同学、评审、企业？决定语气和深度。
- 有没有成品参考/往届样例？只用于格式，不抄内容。

## 2. 结构怎么定

没有模板时，和用户协商一个结构，并说明“这是建议，不是课程模板”。常见结构：

### 论述型（人文/社科）

```text
标题
引言：问题、背景、中心论点
主体：
  1. 论点一 + 证据/文本/案例
  2. 论点二 + 证据/案例
  3. 反方观点/替代解释 + 回应
讨论：局限、未解决的问题、延伸
结论：回到中心论点，不引入新事实
参考文献（如要求）
```

### 调研/案例分析

```text
标题
摘要/关键词（如要求）
一、问题与背景
二、方法/材料/样本
三、发现（分维度，带数据/引文）
四、讨论（解释、对比、局限）
五、结论与建议
参考文献/附录（如要求）
```

### 书评/影评/作品分析

```text
标题
一、作品与作者背景（简短）
二、内容概述（不剧透式复述）
三、分析：主题/结构/语言/人物/视角
四、评价：优点、问题、与其他作品对比
五、结论
参考文献（如要求）
```

## 3. 纯文科写作的硬要求

1. **中心论点明确**：开篇就让读者知道你要论证什么，不要只写“本文分析了……”。
2. **论证链完整**：每个分论点有证据（文本、数据、案例、引文），并解释证据如何支持论点。
3. **有反方/替代解释**：至少处理一个反方观点或另一种解释，说明为什么你的论证更成立。
4. **有局限**：数据/样本/文本范围的限制，不装作全知。
5. **不堆砌**：不要用“背景—现状—问题—对策”四段空话凑字数；每一段都要有信息量。
6. **引用可追溯**：直接引用、数据、案例都要有来源；引文与文末列表一一对应。
7. **语言一致**：术语统一，不混用同义词；避免口语化和情绪化表达。
8. **不编造**：没有数据/访谈/文献就写“缺少/待补”，不要造。

## 4. 格式

- 没有模板时，默认用简洁学术格式：标题黑体/加粗，正文宋体/思源宋体 小四，1.5 倍行距，
  首行缩进 2 字符；但**先问用户**，不要把自己的默认当老师要求。
- 标题层级固定一种：`一、` → `（一）` → `1.` → `（1）`，不要跳级。
- 参考文献按用户/课程要求；没有要求且没有引用，就不要硬加。
- 图表是条件项：有数据要展示才做，不为了“看起来丰富”硬凑。

## 5. 交付前自检

- [ ] 中心论点能用一句话说清
- [ ] 每个分论点都有证据，不是只有观点
- [ ] 有反方/替代解释和回应
- [ ] 有局限，不夸大结论
- [ ] 引用与文末列表一一对应；没有“列了不引/引了不列”
- [ ] 字数只算正文，不含封面/目录/参考文献（按用户口径）
- [ ] 没有编造数据/访谈/文献
- [ ] 结构是用户确认过的，不是“AI 默认模板”
