# 07 人工接管：把做不了/不该自动做的步骤交还给用户

不是所有步骤都能数字化：物理设备、实验室仪器、本人签字、线下访谈、需要登录/验证码的操作。
这时不要硬做，也不要编造结果；生成一张**人工操作卡**，暂停，等用户回传。

## 什么时候用

- 计划里 `action.kind = "manual"` 或 `requires_user = true`；
- GUI 连续失败（窗口找不到、控件找不到、坐标不可靠），且没有别的接口；
- 需要用户本人完成的不可逆/对外动作；
- 用户明确说“这一步我自己来”。

## 生成 `人工操作卡.md`

放在 `<WS>/人工操作卡.md`，内容：

```markdown
# 人工操作卡：<步骤 ID / 名称>

- 为什么要你来做：<物理设备/本人签字/登录/无法自动化>
- 对应实验目的：<P1>
- 预计耗时：<分钟>

## 你要做什么

1. <动作 1，具体到按钮/菜单/参数>
2. <动作 2>
3. <动作 3>

## 做到什么算完成

- [ ] <可观察的验收 1>
- [ ] <可观察的验收 2>

## 要拍什么/留什么

| 证据 ID | 拍什么 | 必须包含 | 存到哪 |
| --- | --- | --- | --- |
| E7 | <窗口/页面/设备> | <关键字段> | `Pictures/E7_xxx.png` |

## 回传方式

- 把文件放进 `<WS>/Pictures/` 或 `<WS>/Data/`；
- 或直接上传给 Agent；
- 不要改文件名里的证据 ID（方便验收）。

## 完成后

告诉 Agent：“<步骤 ID> 已完成，证据在 ...”，然后继续。
```

## 状态怎么走

1. 生成操作卡后：

```bash
python "<SKILL_DIR>/scripts/worker.py" --workspace "<WS>" advance --to WAITING_USER
```

2. 用户完成后，验收证据：
   - 图片：按 `03_screenshot_reviewer.md` 的四查；
   - 数据/日志：文件存在、内容匹配、时间/环境一致；
   - 不确定：标 `需人工复核`，不要硬判。
3. 证据通过后：

```bash
python "<SKILL_DIR>/scripts/worker.py" --workspace "<WS>" resume --back
```

回到进入 `WAITING_USER` 之前的阶段，继续后续步骤。

## 不要做

- 不要替用户点“提交/发送/购买/确认”；
- 不要替用户登录、输密码、过验证码；
- 不要用旧图/网图/其他同学的材料冒充用户回传；
- 不要把“用户说做完了”直接当成证据；还是要看文件/画面。
