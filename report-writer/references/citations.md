# 文献引用规范

## 〇、先确认这份报告要不要参考文献

**不是所有报告都需要。** 判据按优先级：**用户要求 → 指导书 → 模板 → 都没有就不写**。

- 模板写了「参考文献不少于 3 篇」→ **硬要求**，凑够，并**在正文标上标引用**；
- 报告真的引用了论文/法律/标准/书籍/网页 → 要规范著录；
- 纯操作性的实验报告、一条引用都没有 → **不要硬凑**。硬凑出来的文献表多半
  和正文对不上（列而不引），反而比没有更显眼。

确定要写，再往下看格式。

---

报告里一旦引用了文献（论文、法律、标准、书籍、网页），**参考文献表和正文标注都要规范**。
不规范的引用是很容易被扣分的硬伤，而且改起来很便宜——照着模板填就行。

## 一、先看模板有没有规定

**中文报告的模板经常自带著录规范**（"格式说明型模板"的一种）。遇到就严格照抄它的格式与例子，
不要用自己默认的 GB/T 7714 去覆盖它。

实例：某门课的研读报告模板里，直接印着完整的参考文献写法——

```
一、参考文献的类型
M——专著  C——论文集  N——报纸文章  J——期刊文章  D——学位论文  R——报告
不属于上述类型的，用 Z 标识。

二、参考文献的格式及举例
1.期刊类  [序号]作者.篇名[J].刊名，出版年份，卷号（期号）：起止页码.
2.图书类  [序号]作者.书名[M].出版地：出版社，出版年份：起止页码.
3.报纸类  [序号]作者.篇名[N].报纸名，出版日期（版次）.
4.论文集  [序号]作者.篇名[C].出版地：出版者，出版年份：起始页码.
5.学位论文 [序号]作者.篇名[D].出版地：保存者，出版年份：起始页码.
6.研究报告 [序号]作者.篇名[R].出版地：出版者，出版年份：起始页码.
7.条例     [序号]颁布单位.条例名称.发布日期     例：[15] 中华人民共和国科学技术委员会.科学技术期刊管理办法[Z].1991—06—05
8.译著     [序号]原著作者. 书名[M].译者，译.出版地：出版社，出版年份：起止页码.

英文文献：作者"姓在前名在后"，如 Malcolm Richard Cowley → Cowley, M.R.；
         两位作者用 & 连接，第二位也把姓放后面，如 Norris, F. & I.Gordon.；
         书名、报刊名用斜体。
```

模板没写时，用下面的 GB/T 7714 顺序编码制。

## 二、GB/T 7714 顺序编码制

### 正文标注

- 在引用处用方括号序号标注，**序号设为上标（右上角标）**：

  > 有研究表明，该方法在低信噪比下仍能保持稳定<sup>[1]</sup>。

- 同一处引多篇：`[1-3]`（连续）或 `[1,3,5]`（不连续）。
- 序号放在**所引内容之后、句末标点之前**。
- 序号必须与文末参考文献表一一对应——**列了却没在正文引用，或引用了却没列，都是硬伤**。

用 `docx_kit.cite()` 生成上标：

```python
cur.put(K.body(caps, '有研究表明，该方法在低信噪比下仍能保持稳定<<cite:1>>。'))
```

或者手动标：

```python
p = K.new_p(indent=True)
p.append(K.run('……仍能保持稳定'))
p.append(K.cite('1'))          # 生成上标 [1]
p.append(K.run('。'))
```

### 文末参考文献表

- 标题写 `参考文献`，位于正文之后。
- **按正文首次引用的顺序编号**（顺序编码制的核心）。
- 每条格式：`[序号] 作者.题名[文献类型标识].出版项.`

| 类型 | 格式 | 例子 |
| --- | --- | --- |
| 期刊 J | 作者.篇名[J].刊名，年，卷(期)：起止页码. | `[1] 王海粟.浅议会计信息披露模式[J].财政研究，2004，21(1)：56-58.` |
| 专著 M | 作者.书名[M].出版地：出版社，年：页码. | `[4] 葛家澍，林志军.现代西方财务会计理论[M].厦门：厦门大学出版社，2001：42.` |
| 学位论文 D | 作者.篇名[D].出版地：保存者，年：页码. | `[11] 张筑生.微分半动力系统的不变集[D].北京：北京大学数学系数学研究所，1983：1-7.` |
| 报纸 N | 作者.篇名[N].报纸名，出版日期(版次). | |
| 论文集 C | 作者.篇名[C].出版地：出版者，年：起始页码. | |
| 报告 R | 作者.篇名[R].出版地：出版者，年：起始页码. | |
| 标准/法规 Z | 颁布单位.名称[Z].发布日期. | `[15] 中华人民共和国科学技术委员会.科学技术期刊管理办法[Z].1991—06—05` |
| 电子资源 EB/OL | 作者.题名[EB/OL].(发布日期)[引用日期].URL. | |

作者多人时列前三位，其后加"等"（英文用 et al.）。

### 英文文献细则

- 姓在前名在后，名只留首字母：`Cowley, M.R.`
- 两位作者：`Norris, F. & I.Gordon.`
- 书名、刊名用**斜体**。

## 三、常见错误

- ❌ 正文写了 `[1]` 但没设上标——看起来像普通方括号，不符合规范。
- ❌ 参考文献表和正文序号对不上：文中只引到 `[3]`，表里却列了 5 条。
- ❌ 序号不是按**首次引用顺序**排的（顺序编码制要求）。
- ❌ 缺文献类型标识 `[J]` `[M]` `[Z]`。
- ❌ 期刊缺卷期或页码。
- ❌ 法律、标准这类没写发布日期。
- ❌ 中英文标点混用（中文条目里用了英文逗号）。

## 四、写进报告前的检查

- [ ] 模板若自带著录规范，是否严格照它写的？
- [ ] 正文每处引用都是**上标** `[n]`？
- [ ] 正文序号与文末列表**一一对应**，无孤立条目？
- [ ] 列表按**首次引用顺序**编号？
- [ ] 每条都有**文献类型标识** `[J]`/`[M]`/`[Z]`…？
- [ ] 英文文献符合"姓前名在后 + 斜体"？
- [ ] 检索来源可靠（不是随便找的网页），**不要编造文献**。
